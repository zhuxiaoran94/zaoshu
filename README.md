# Mock造数工具

面向测试人员的浏览器端测试数据工作台。内置 120+ 字段生成类型和用户、电商、金融、游戏、社区、物流、测试通用七类场景，无需上传任何数据即可生成多表关联测试数据。

当前版本：**2.3.0 SQL DDL 建模版**。网站没有匿名写入接口，访客的数据与配置仅保存在各自浏览器中。

## 功能

- 可视化字段配置、固定随机种子、唯一性和跨表外键
- 随机、真实分布、边界、异常、Pairwise 组合模式
- 异常数据注入与 `_mock_meta` 预期结果标记
- 数据质量检查、覆盖报告和业务状态链
- JSON、JSONL、CSV、TSV、XLSX、MySQL、PostgreSQL、SQLite 导出
- Postman 数据、TypeScript Fixture 和 Markdown 报告导出
- 可选本地自定义数据池，所有配置保存在浏览器
- 项目配置安全备份、恢复内置模板和清除本地数据
- CSV/XLSX 公式注入防护、SQL 标识符转义和严格配置校验
- 数据表新增、复制、重命名、排序、删除及关系视图
- 项目结构修改支持 30 步撤销和重做
- 生成前即时诊断循环依赖、失效引用、名称冲突、范围错误和唯一值容量
- 阻断问题不会启动生成，诊断结果支持点击定位到对应表和字段
- 可视化配置 AND/OR 条件字段，支持 7 种比较操作与不满足时置空或移除
- 电商模板内置“支付成功才生成支付时间”的可运行条件示例
- Pairwise 支持 2–8 个维度、非法组合排除、关键组合强制包含和 100% 合法参数对覆盖审计
- Pairwise 用例可直接导出 JSON、CSV 和 Postman Runner 数据
- 状态链支持实体数量、终止状态、停留时长和状态倒退/跳过/重复三类异常
- 状态事件包含稳定 Trace ID、事件序号、停留时长和异常标记，可导出 JSON/CSV
- 首次完整打开后支持 PWA 安装和离线使用，断网仍可生成、预览及读取本地项目
- 新版本静默下载后由用户确认刷新，编辑中的项目不会突然丢失
- 最多保存 20 个命名项目快照，一键恢复任意 Schema 版本
- 快照可与当前项目进行项目、数据表、字段三级差异比较
- 结果表支持按字段锁定并重新生成单行，主键自动保持，外键继续来自有效父表
- 手工编辑会按字段类型解析；编辑、删行或重生成后质量报告立即重算
- 字段统计展示缺失率、空值率、唯一率、范围和高频值 Top 3
- 可选导入 OpenAPI 3 JSON 或普通 JSON 样例，先预览再确认建立项目
- 自动推断表、字段类型、格式生成器、枚举、范围、必填性及常见 ID 外键关系
- 导出支持 JSON/JSONL/CSV/TSV/YAML/XML/XLSX、三种 SQL 与六类测试 Fixture
- 每次导出均为 ZIP，内附 Manifest、SHA-256、种子、Schema 版本和异常比例
- 完整交付包一次包含全量 JSON、逐表 CSV、三种 SQL 与覆盖报告
- Faker 生成引擎、Web Worker 和 XLSX 均按需加载，首屏主 JS 从约 948 KB 降至约 395 KB
- 构建内置 450 KB 首屏 JS 性能预算，超出即阻止版本发布
- 支持 MySQL、PostgreSQL、SQLite `CREATE TABLE` DDL 导入，推断列、主键、唯一约束和外键
- DDL 仅作文本结构解析，忽略 DROP/INSERT 等语句，不连接或执行数据库操作

完整版本记录见 [CHANGELOG.md](./CHANGELOG.md)，已实现与待实现功能见 [ROADMAP.md](./ROADMAP.md)。

## Cloudflare Pages

- 构建命令：`npm run build`
- 输出目录：`dist`
- Node.js：18 或更高版本

项目没有服务端接口，所有造数、检查与导出均在浏览器本地完成。

### 为什么公开部署不容易被别人搞坏

- 站点是 Cloudflare Pages 静态文件，没有数据库和公共写入 API。
- 用户配置、业务字典和生成结果均不上传，访客之间互不影响。
- 导入文件有 1 MB 体积限制，并校验表数、字段数、行数和字段格式。
- Schema 导入不解析远程 `$ref`、不发送网络请求、不执行输入中的代码。
- CSP、禁止 iframe 嵌入、权限策略和跨源资源策略由 `_headers` 下发。
- Service Worker 仅处理同源 GET 静态资源，不缓存第三方响应或任何写请求。
- 大任务进入 Web Worker，单项目总生成量限制为 200,000 条，可主动取消。

公开仓库不能阻止别人阅读或复制前端源码，但访客不能通过网站修改仓库、部署文件或其他用户的数据。
